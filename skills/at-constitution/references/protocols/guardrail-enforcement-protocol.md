## 1. 核心理论：法律级工程刚性约束

在多 Agent 协同与自治长跑中，缺乏顶层制度约束会导致技术栈野蛮扩散与架构底线破损。
`at-constitution` 确立**项目工程宪章 (Constitution)** 的法律地位：
- **高于任何局部优化**：任何“为了图快”而违背宪章的行为均属非法；
- **全阶段前置守卫**：从需求预研（`at-assess`）、规格拟定（`at-spec`）到代码审查（`at-review`），全流程必须首先校验宪章符合度；
- **机器可强制验证**：宪章中的规约必须清晰、二元（符合 vs 违背），杜绝模棱两可。

```mermaid
flowchart TD
    Action["任何工程动作 (引入依赖 / 修改架构 / 编写代码)"] --> Check{"宪章合规性前置核验 (Check CONSTITUTION.md)"}
    Check -- 100% 符合宪章 --> Proceed["准予推进后续步骤"]
    Check -- 触碰宪章红线 --> Break["【立即熔断】阻断操作并发出高危告警！"]
    Break --> Human{"人类是否显式授权特批豁免？"}
    Human -- 否 --> Abort["回滚/推翻违规方案"]
    Human -- 是 (严格留痕) --> ADR["输出 ADR 记录特批豁免与技术债"] --> Proceed
```

## 2. 宪章在全生命周期的前置守卫机制

宪章作为全局前置切面嵌入各个技能：
1. **可行性预研 (`at-assess`)**：优先核查提案是否引入了宪章禁止的组件或架构模式；
2. **增量规格拟定 (`at-spec`)**：规格必须继承宪章中声明的通用不变式（如空集合安全契约、零明文凭据）；
3. **工序拆解 (`at-plan`)**：微任务必须包含宪章规定的质量门禁指令（如必须通过 `validate.py`）；
4. **测试驱动开发 (`at-tdd`)**：严禁在测试中混入真实外网地址或生产凭据；
5. **代码审查 (`at-review`)**：任何违背宪章的改动直接标定为 🔴 Blocker 阻断项。

## 3. 多模块与 Monorepo 依赖 DAG 防腐红线 (Module Dependency Invariants)

在包含多个子模块的复杂工程中，模块间依赖必须严格遵守有向无环图单向流向：

```mermaid
flowchart TD
    Contract["契约/接口层 (*-api)"]
    Domain["核心领域层 (*-core / *-domain)"]
    Infra["基础设施层 (*-infra / 持久层)"]
    App["应用入口层 (*-app / *-gateway)"]

    App --> Domain
    App --> Infra
    Domain --> Contract
    Infra --> Contract
```

1. **底层契约与公共模块纯粹性**：
   - 接口契约模块（`*-api`）只允许包含 DTO、接口定义与参数校验注解，**严禁引入任何业务实现库、数据库连接或 Spring MVC 运行时**；
   - 基础公共模块（`*-common`）严禁反向依赖具体的业务微服务模块（`*-service`）。
2. **禁止双向循环依赖**：
   - 子模块 $A$ 依赖子模块 $B$ 时，$B$ 绝对严禁通过 Maven/Gradle/pnpm 依赖 $A$；
   - 两个平级业务微服务之间严禁互相直接注入实现类，必须通过 RPC / 消息队列或契约解耦。
3. **构建配置依赖扫描**：
   - 任何改动若向 `pom.xml`、`package.json` 或 `build.gradle` 增加了新的模块依赖，必须首先核验证明该依赖边符合 DAG 单向拓扑，否则立即熔断。

## 4. 违规即熔断 (Circuit Breaker) 原则

一旦扫描到以下任一触碰宪章红线的行为，Agent 必须立即**强制熔断停机**：
- **未授权依赖引入**：在构建配置中擅自引入非白名单第三方依赖或反向模块依赖；
- **破坏无状态设计**：在单例服务中定义可变共享成员变量；
- **持久层 N+1 穿透**：在循环体内发起数据库查询或远程 RPC；
- **凭据裸露泄露**：在代码、配置或文档中写入明文密码、API Token 或物理本地绝对路径。

---

## 5. 显式授权与受控豁免机制

项目宪章是刚性的，但在极端业务场景下允许受控豁免：
1. **人类双重确认**：必须由人类开发者在对话框中显式给出明确豁免指令；
2. **强制 ADR 留痕**：任何豁免必须强制唤起 `at-adr` 记录《架构偏差决策记录》，注明背负的技术债务与计划还债周期。

## 6. 宪章版本演进与守卫准出标准

- 宪章文件默认存放于工程根目录 `CONSTITUTION.md`；
- 每次修订必须标注修订人、生效日期与关联版本号；
- 正文严格遵循盘古之白排版规范，全文档杜绝任何 `file:///` 或本地物理盘符泄漏。
