# 案例样本：电商交易中台 Agent 行为准则 (Order Center AGENTS.md)

以下为电商交易微服务中台针对 AI 编码助手制定的实际落地规约样本。

---

## 1. 业务上下文与架构模式

- **核心语言与框架**：Java 21, Spring Boot 3.2, MyBatis-Plus, Redis, Apache RocketMQ;
- **架构模式**：DDD 领域驱动设计，四层经典架构（用户接入层、应用编排层、领域核心层、基础设施层）；
- **数据一致性**：最终一致性方案，交易链路分布式事务采用本地消息表 + MQ 确认机制。

---

## 2. 领域开发硬性红线

1. **金额计算严禁使用浮点数**：
   - 涉及金额的所有字段与运算必须使用 `BigDecimal` 或自研 `Money` 领域值对象；
   - 严禁使用 `float` 或 `double` 类型；构造 `BigDecimal` 必须通过字符串入参 `new BigDecimal("10.00")` 或 `BigDecimal.valueOf()`。
2. **读写分离与缓存穿透防御**：
   - 高频查询接口必须引入布隆过滤器防止缓存穿透；
   - 缓存数据写入必须设置带微随机扰动的过期时间，防止缓存雪崩。
3. **幂等性保障**：
   - 所有扣减库存、创建订单等有状态写操作必须强制提供业务防重 Key（幂等 Token）。

---

## 3. Git 与协作纪律

- 任务执行完毕后必须保持在未提交状态；
- 等待人类 Review 确认后方可按照 `feat(order): <中文说明>` 格式提交；
- 严禁自行推送至远程主干分支。
