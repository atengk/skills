## 4. 最终技术决策与架构裁定

**最终采纳：方案 3。**

### 正面技术影响与业务收益
- 原生支持高效 GIN 索引，复杂嵌套 JSON 检索耗时从 350ms 降至 15ms。
- 减少了一套独立的 NoSQL 数据库运维实例，降低基础设施开销。

### 负面潜在影响与应对妥协策略
- **风险**：开发人员对 PG 独有特性与连接池（PgBouncer）尚不熟悉。
- **应对措施**：组织专项技术分享会，并在基础框架层封装统一的连接池与慢 SQL 拦截器。
